# 1. 研究背景

繊維型ひずみセンサは、材料に生じる変形を電気抵抗の変化として計測するセンサである。柔軟性や軽量性を有することから、ウェアラブルデバイス、構造物の状態監視、人体動作の計測など、さまざまな応用が期待されている。

本研究では、繊維型センサの二つの電極から得られる電気抵抗信号を入力とし、機械的ひずみ（strain）を推定する回帰モデルを構築する。単純な人工ニューラルネットワーク（Artificial Neural Network: ANN）を基準モデルとし、特徴量設計、ネットワーク構造、時系列モデル、ハイパーパラメータ最適化などを段階的に検討してきた。

本課題における重要な問題は、温度変化によるセンサ特性のドリフトである。同一のひずみであっても、周囲温度が異なると電気抵抗の絶対値や変化傾向が異なる可能性がある。そのため、単一の温度条件で高い予測精度を達成したモデルが、未知の温度条件でも同様に機能するとは限らない。

これまでの実験では、同一データセット内で学習および評価を行う場合には比較的高い決定係数を得られた。一方、学習時に含まれていない温度のデータを予測する実験では性能が大幅に低下した。この結果から、現在の研究課題は、単純なモデル精度の向上だけではなく、温度変化に対する汎化性能の確保へと移行している。

# 2. 研究目的および研究課題

本研究の最終的な目的は、繊維型センサから得られる電気抵抗信号を用いて、ひずみを高精度かつ安定的に予測できる手法を構築することである。

現在までに設定した具体的な研究目的は以下のとおりである。

1. 基準となるANNモデルを再現し、比較可能な評価基準を確立する。
2. 温度、電極間抵抗差、抵抗比などの特徴量が予測精度に与える影響を評価する。
3. ANNのネットワーク構造を改善し、特徴量設計とモデル構造の効果を分離して検証する。
4. LSTM、CNN-1D、CNN-LSTMなどの時系列モデルを比較する。
5. Optunaを用いてANNのハイパーパラメータを最適化する。
6. 未知温度に対するモデルの汎化性能を評価する。
7. Continuous Wavelet Transform（CWT）による時間周波数表現の有効性を予備的に検討する。

以上を踏まえ、本研究では次の研究課題を扱う。

- 特徴量設計とネットワーク構造のどちらが精度向上に大きく寄与するか。
- 時系列依存性を考慮することで、ANNより安定した予測が可能になるか。
- 複雑なモデル構造は、単純なANNより高い精度を実現できるか。
- ハイパーパラメータ最適化による改善は再現性を有するか。
- 異なる温度条件で取得されたデータに対してモデルが汎化できるか。

# 3. データセットと問題設定

## 3.1 データセット

本プロジェクトでは、異なる温度条件で収集された五つのCSVデータセットを使用している。各データセットの概要を表1に示す。

**表1　データセットの概要**

| データセット | サンプル数 | おおよその温度 | 主評価での使用 |
|---|---:|---:|---|
| dataset0 | 11,776 | 21°C | 使用しない |
| dataset1 | 23,053 | 33°C | 使用する |
| dataset2 | 23,227 | 43°C | 使用する |
| dataset3 | 21,497 | 52°C | 使用する |
| dataset4 | 23,077 | 62°C | 使用する |

dataset0は一つの実験系列のみを含み、サンプルまたはデモ用データである可能性がある。そのため、主要なモデル比較ではdataset1からdataset4までを使用した。

各データセットには次の変数が含まれる。

- `Electrode1_resistance`：電極1の抵抗値
- `Electrode2_resistance`：電極2の抵抗値
- `Temperature`：周囲温度
- `Strain`：予測対象となるひずみ
- `Experiment`：実験番号
- `Idx`：時系列上のインデックス

## 3.2 データの特徴

各データセット内の温度変動は約0.2°C未満であり、ほぼ一定である。ひずみの範囲はデータセット間でおおむね共通しており、約0から0.5までである。

一方、電気抵抗のスケールは温度条件によって大きく異なる。全データセットを単純に結合した場合、電気抵抗とひずみの相関係数は約0.02と低い値になった。この低い相関は、電気抵抗がひずみと無関係であることを直接意味するものではない。温度ごとに抵抗値の基準スケールが異なるため、複数温度のデータを混合すると関係性が見えにくくなることが主な要因と考えられる。

## 3.3 回帰問題の定義

基本的な入力は二つの電極抵抗値であり、出力はひずみである。

\[
(\mathrm{Electrode1\ resistance},\ \mathrm{Electrode2\ resistance})
\rightarrow \mathrm{Strain}
\]

特徴量設計の段階では、温度に加えて、二つの電極抵抗値から計算した抵抗差 `delta_R` および抵抗比 `R_ratio` も評価した。

# 4. 実験方針および評価方法

## 4.1 データ分割と前処理

時系列情報を保持するため、データの分割ではシャッフルを行っていない。データ前半を学習に、後半をテストに使用することで、時間的に後続する系列に対する予測性能を評価した。

MinMaxScalerは学習データのみに適合させ、その後、同じ変換器を用いてテストデータを変換した。テストデータの統計量を前処理に使用しないことで、データリーケージを防止した。

## 4.2 実験比較の原則

比較実験では、可能な限り一度に一つの要因のみを変更した。例えば、特徴量の効果を調べる場合はモデル構造を固定し、ネットワーク構造の効果を調べる場合は入力特徴量を固定した。

結果が初期値に依存する可能性を考慮し、主要な評価では乱数seedとして0、42、123を使用した。単一の最良結果のみを報告するのではなく、複数seedの平均値と標準偏差を使用した。

学習時にはEarlyStoppingを使用したが、EarlyStoppingのみで過学習を防止できるとは限らない。そのため、学習損失と検証損失、ならびに学習データとテストデータの性能差も確認した。

## 4.3 評価指標

主な評価指標には決定係数R²を用いた。必要に応じてMSE、MAE、RMSEも算出した。

R²が1に近いほど、モデルが目的変数の変動をよく説明している。R²が0付近の場合、平均値を常に予測する方法と同程度である。R²が負の場合、モデルの予測がテストデータの平均値を使用する単純な方法よりも悪いことを示す。

# 5. 研究進捗および実験結果

## 5.1 Phase 1：探索的データ分析

Phase 1では、データの構造、ひずみの分布、温度条件、電気抵抗とひずみの関係を確認した。

主な結果は以下のとおりである。

- 五つのデータセット全体で約102,000サンプルが存在した。
- 各データセット内では温度がほぼ一定であった。
- ひずみの範囲はデータセット間で比較的近かった。
- 複数温度のデータを結合すると、電気抵抗とひずみの単純相関が非常に低くなった。
- 温度ごとに抵抗値のスケールが異なり、thermal driftへの対応が必要であることが確認された。

## 5.2 Phase 2：基準ANNモデル

基準モデルとして、次の単純なANNを使用した。

`Input(2) → Dense(4, ReLU) → Dense(1)`

最適化手法はAdam、学習率は1×10⁻⁴、エポック数は50、バッチサイズは32とした。結果を表2に示す。

**表2　基準ANNモデルの評価結果**

| データセット | R²平均 | 標準偏差 |
|---|---:|---:|
| ds1 | 0.628 | 0.445 |
| ds2 | 0.342 | 0.391 |
| ds3 | 0.856 | 0.030 |
| ds4 | 0.720 | 0.060 |
| 平均 | **0.637** | - |

ds3およびds4では比較的高いR²を示したが、ds1とds2ではseedによる変動が大きかった。特に標準偏差が0.4前後となり、単純なANNは学習初期値に対して不安定であることが分かった。

## 5.3 Phase 3：特徴量設計

Phase 3ではモデル構造を基準ANNに固定し、入力特徴量のみを変更した。これにより、特徴量設計の効果を単独で評価した。

**表3　入力特徴量による性能比較**

| 特徴量 | ds1 | ds2 | ds3 | ds4 | 平均R² |
|---|---:|---:|---:|---:|---:|
| E1 + E2 | 0.707 | 0.483 | 0.893 | 0.641 | 0.681 |
| E1 + E2 + Temperature | 0.817 | 0.397 | 0.897 | 0.697 | 0.702 |
| E1 + E2 + delta_R + R_ratio | 0.900 | 0.808 | 0.762 | 0.716 | **0.797** |
| 全5特徴量 | 0.714 | 0.692 | 0.656 | 0.743 | 0.701 |

`delta_R`と`R_ratio`を追加した場合、平均R²は0.797となり、基準特徴量より高い結果を示した。一方、Temperatureを追加しただけでは改善が限定的であった。これは、各データセット内で温度がほぼ一定であり、同一データセット内の各サンプルを区別する情報として機能しにくいためと考えられる。

また、すべての特徴量を同時に使用しても性能は向上しなかった。入力変数を増やすことが常に精度向上につながるわけではないことが確認された。

## 5.4 Phase 4：Deep ANNとアブレーション実験

Phase 4では、特徴量とネットワーク構造の効果を分離するため、2×2のアブレーション実験を実施した。

**表4　特徴量とANN構造のアブレーション結果**

| Cell | ネットワーク構造 | 特徴量 | 平均R² |
|---|---|---|---:|
| A | Dense(4) | E1, E2 | 0.541 |
| B | Dense(4) | 全5特徴量 | 0.685 |
| C | Dense(64 → 32 → 16) | E1, E2 | **0.846** |
| D | Dense(64 → 32 → 16) | 全5特徴量 | 0.772 |

Cell AからCell Bへの変化は特徴量の効果を表し、R²は0.144増加した。一方、Cell AからCell Cへの変化はネットワーク構造の効果を表し、R²は0.305増加した。

したがって、本実験条件では、特徴量の追加よりもネットワーク構造の改善が大きな効果を示した。最良構成は、二つの基本抵抗値のみを入力とするDense(64 → 32 → 16)のANNであった。

## 5.5 Phase 5：LSTM

時系列依存性を考慮するため、20ステップのsliding windowを入力とするLSTMを構築した。

`LSTM(64) → LSTM(32) → Dense(16) → Dense(1)`

**表5　ANNとLSTMの比較**

| データセット | ANN Phase 4 | LSTM Phase 5 |
|---|---:|---:|
| ds1 | 0.908 | **0.937** |
| ds2 | 0.835 | **0.859** |
| ds3 | **0.910** | 0.843 |
| ds4 | **0.731** | 0.663 |
| 平均 | **0.846** | 0.826 |

LSTMはds1およびds2でANNより高い性能を示した。特にds2では、ANNで見られたseed依存性が軽減され、標準偏差が0.261から0.038へ低下した。一方、ds3およびds4ではANNの方が高いR²を示し、全体平均でもANNを上回らなかった。

この結果から、時系列情報は一部のデータセットでは有効であるが、すべての温度条件で同じ効果をもたらすわけではないことが分かった。

## 5.6 Phase 6：CNN-1D

局所的な時系列パターンを抽出するため、一次元畳み込みニューラルネットワークを評価した。

**表6　CNN-1Dの評価結果**

| ds1 | 0.900 |
| ds2 | 0.782 |
| ds3 | 0.838 |
| ds4 | 0.647 |
| 平均 | **0.792** |

## 5.7 Phase 7：CNN-LSTM Hybrid

CNNを局所特徴抽出器として使用し、その出力をLSTMで処理するhybridモデルを構築した。

| ds2 | 0.856 |
| ds3 | 0.885 |

## 5.8 Phase 8：未知温度に対する汎化性能

Phase 8では、同一データセット内の性能ではなく、学習時に存在しない温度条件への汎化性能を評価した。

実験は次の二つの条件で実施した。

1. Leave-One-Dataset-Out：三つの温度データで学習し、残り一つの温度で評価する。
2. Extrapolation：33°Cから52°Cのデータで学習し、62°Cのデータで評価する。

**表8　Leave-One-Dataset-Outによる未知温度評価**

| テストデータ | 学習データ | ANN R² | LSTM R² |
|---|---|---:|---:|
| ds1（33°C） | ds2 + ds3 + ds4 | -14.376 | -40.335 |
| ds2（43°C） | ds1 + ds3 + ds4 | -0.719 | -0.542 |
| ds3（52°C） | ds1 + ds2 + ds4 | 0.013 | 0.010 |
| ds4（62°C） | ds1 + ds2 + ds3 | -2.120 | -8.008 |

ほとんどの条件でR²が負となり、同一温度内で得られた高い性能を未知温度で再現できなかった。ds3ではR²が約0.01であったが、これは平均値予測とほぼ同程度であり、十分な予測性能とはいえない。

**表9　33～52°Cから62°Cへの外挿結果**

| モデル | R²平均 | 標準偏差 | 判定 |
|---|---:|---:|---|
| ANN | 0.050 | 0.044 | 十分に汎化できない |
| LSTM | -7.251 | 7.335 | 汎化できない |

この実験により、現在のモデルにおける主要な問題はthermal driftであることが明確になった。学習温度で適合したMinMaxScalerでは、未知温度における異なる抵抗スケールを適切に変換できない。

R²が負であることは望ましい結果ではないが、実運用上の限界を明確にした重要な実験結果である。同一温度内の高い精度だけを報告した場合、実環境での性能を過大評価する可能性がある。

## 5.9 Phase 9：Optunaによるハイパーパラメータ最適化

Phase 4のDeep ANNを基礎として、Optunaを用いたハイパーパラメータ探索を実施した。探索対象は、隠れ層数、各層のユニット数、dropout率、学習率、バッチサイズである。

各データセットに対して50 trialを実施した。探索時は計算時間を考慮してseed 0を使用し、得られた最良構成を三つのseedで再評価した。

**表10　Phase 4 ANNとOptuna最適化モデルの比較**

| データセット | ANN Phase 4 | Optuna Phase 9 | 標準偏差 | 差 |
|---|---:|---:|---:|---:|
| ds1 | 0.908 | 0.791 | 0.036 | -0.117 |
| ds2 | 0.835 | 0.897 | 0.035 | +0.062 |
| ds3 | 0.910 | 0.932 | 0.005 | +0.022 |
| ds4 | 0.731 | 0.779 | 0.006 | +0.048 |
| 平均 | 0.846 | **0.850** | - | **+0.004** |

Optunaモデルはds2、ds3、ds4で改善し、全体平均R²は0.850となった。一方、ds1では0.117低下した。探索時のds1のR²は0.933であったが、三つのseedによる再評価では平均0.791となった。この差は、単一seedを用いた探索が特定の初期値に過適合した可能性を示している。

平均改善量は0.004にとどまり、Phase 4で手動設定したDense(64 → 32 → 16)が既に良好な構成であったことが確認された。ハイパーパラメータ探索は有用であるが、探索結果の再現性を複数seedで検証する必要がある。

## 5.10 Phase 10：CWTとCNN-2Dによる予備実験

Phase 10では、一次元の抵抗信号をContinuous Wavelet Transformによって二次元のscalogramへ変換し、CNN-2Dで処理する方法を予備的に検討した。

Morlet wavelet、32 scales、64ステップのwindowを使用した。二つの電極信号から生成したscalogramをチャネル方向に結合し、CNN-2Dへの入力とした。

**表11　CWT + CNN-2DとCNN-1Dの比較**

| データセット | CWT + CNN-2D | 標準偏差 | CNN-1D | 差 |
|---|---:|---:|---:|---:|
| ds1 | 0.855 | 0.087 | 0.900 | -0.045 |
| ds2 | 0.491 | 0.065 | 0.782 | -0.291 |
| ds3 | 0.853 | 0.043 | 0.838 | +0.015 |
| ds4 | 0.596 | 0.017 | 0.647 | -0.051 |
| 平均 | **0.699** | - | **0.792** | **-0.093** |

ds3では0.015の小さな改善が見られたが、その他のデータセットでは性能が低下した。特にds2では0.291の低下となった。全体平均もCNN-1Dより0.093低かった。

現時点では、CWTによる時間周波数表現が本データに有効であるとは結論づけられない。ただし、本実験ではwavelet、scale数、window長およびCNN構造を十分に探索していない。そのため、Phase 10は正式な最終結果ではなく、予備実験として位置づける。

平均R²のみではOptunaモデルが最良である。しかし、Phase 4との差は0.004であり、ds1では性能が低下している。そのため、計算コスト、安定性、構造の単純さを考慮すると、Phase 4のDeep ANNも有力なモデルである。

データセットごとの最良モデルを表13に示す。

**表13　各データセットにおける最良モデル**

| データセット | 最良モデル | R² |
|---|---|---:|
| ds1（33°C） | LSTM Phase 5 | **0.937** |
| ds2（43°C） | Optuna Phase 9 | **0.897** |
| ds3（52°C） | Optuna Phase 9 | **0.932** |
| ds4（62°C） | Optuna Phase 9 | **0.779** |

単一モデルがすべての温度条件で最良となったわけではない。これは、温度条件ごとに信号特性や時間依存性が異なる可能性を示している。

# 7. 結果の分析と主な知見

## 7.1 ネットワーク構造の効果

Phase 4のアブレーションでは、特徴量追加による改善が+0.144であったのに対し、ネットワーク構造の改善は+0.305であった。本実験範囲では、手動で追加した特徴量よりも、十分な表現能力を持つANN構造の方が大きく寄与した。

また、Deep ANNに全特徴量を入力したCell Dは、基本的な二抵抗値のみを使用したCell Cより低い性能となった。派生特徴量が元の信号から計算されるため、十分な容量を持つネットワークでは重複情報となった可能性がある。

## 7.2 時系列モデルの効果

LSTMはds1およびds2で有効であり、特にds2で学習の安定性を改善した。一方、ds3およびds4ではANNを下回った。この結果から、すべてのデータセットに共通する長期依存性が存在するとは断定できない。

CNN-1Dは局所パターンの抽出を目的としたが、LSTMおよびANNを上回らなかった。CNN-LSTMも同様に最良性能を達成できず、複雑化による過学習が見られた。モデル構造はデータの性質に合わせて選択する必要があり、層数や機能を増やすだけでは改善しない。

## 7.3 ハイパーパラメータ探索の効果

Optunaによる平均改善は+0.004であり、Phase 4のANNが既に良好な設定であったことが分かった。一方、データセット別に見るとds2、ds3、ds4では改善しているため、探索自体が無意味であるわけではない。

ds1の結果は、探索時に単一seedのみを使用する危険性を示している。今後は複数seedの平均値を目的関数とするか、探索用と最終評価用のseedを分離する必要がある。

## 7.4 Thermal driftの影響

本研究における最も重要な知見は、同一温度内の高い性能が未知温度への汎化を保証しないことである。Phase 8では、同一データセット内でR²が0.8から0.9程度であったモデルでも、未知温度ではR²が大幅に低下した。

主な原因として、温度により抵抗値の基準スケールが変化することが考えられる。Temperatureを単純な入力特徴量として追加するだけでは、各データセット内で温度がほぼ一定であるため、温度と抵抗スケールの連続的な関係を十分に学習できない。

したがって、次の研究段階では同一温度内のR²をわずかに改善することよりも、温度変化を明示的に扱う学習方法を優先する必要がある。

# 8. 現時点での課題と限界

本研究には以下の課題と限界がある。

1. 各データセットは、ほぼ一つの温度条件のみを表している。
2. 各温度に含まれる独立した実験系列の数が限られている。
3. 同一データセット内の評価だけでは、実環境に対する汎化性能を保証できない。
4. Optuna探索ではseed 0のみを使用しており、探索結果が特定の初期値に依存した可能性がある。
5. Phase 10ではwavelet、scale数、window長、CNN構造を十分に探索していない。
6. Domain adaptationや未知温度でのfine-tuningは未実施である。
7. 完全に独立した外部データセットによる評価は行っていない。
8. 推論時間、メモリ使用量、リアルタイム処理性能については未評価である。
9. 一部のモデルでは学習データとテストデータの性能差が大きく、過学習評価をさらに統一する必要がある。

これらの制約を踏まえると、現時点の結果は、特定温度内でのモデル比較としては有効であるが、任意の温度環境にそのまま適用できる段階には達していない。

# 9. 今後の研究計画

今後は以下の順序で研究を進める予定である。

## 9.1 過学習評価の統一

Phase 4、Phase 5、Phase 9の主要モデルについて、学習R²、テストR²、両者の差、およびlearning curveを同じ形式で再整理する。これにより、平均R²だけでは確認できないモデルの安定性を比較する。

## 9.2 Phase 10の整理

CWT + CNN-2Dの結果を予備的なnegative resultとして記録する。追加検証を行う場合は、waveletの種類、scale数、window長およびネットワーク構造を一つずつ変更し、効果を分離して評価する。

## 9.3 温度条件付きモデル

Temperatureを単純な入力値として追加するだけでなく、温度に応じて中間表現や正規化を変化させるtemperature-conditioned modelを検討する。ただし、その有効性は実験によって検証する必要がある。

## 9.4 少量データによるcalibrationとfine-tuning

未知温度で少数のラベル付きサンプルを取得できる状況を想定し、少量データによるcalibrationまたはfine-tuningを評価する。必要なサンプル数と性能の関係を調査する。

## 9.5 Domain adaptation

学習温度と未知温度の特徴分布を近づける方法として、Domain-Adversarial Neural Network（DANN）などのdomain adaptation手法を検討する。まずは温度条件をdomain labelとして扱えるかを確認する。

## 9.6 追加baseline

必要に応じてRandom Forest、XGBoost、Support Vector Regressionなどの従来型機械学習モデルを追加し、深層学習モデルの利点が十分に存在するかを確認する。

## 9.7 評価方法の拡張

複数seedに加え、複数の時系列分割や実験単位の交差検証を行い、結果の信頼性を高める。可能であれば、追加温度または外部データを取得し、より厳密な外部評価を実施する。

# 10. 進捗のまとめ

本研究では、探索的データ分析、基準ANN、特徴量設計、Deep ANN、LSTM、CNN-1D、CNN-LSTM、未知温度評価、Optunaによる最適化、およびCWTを用いた予備実験までを実施した。

同一データセット内の評価では、基準ANNの平均R² 0.637から、Optunaモデルの0.850まで改善した。Phase 4のDeep ANNも平均R² 0.846を達成しており、Optunaモデルとの差は0.004である。モデルの単純さと安定性を考慮すると、Deep ANNは現在も重要な基準モデルである。

LSTMはds1およびds2で有効であったが、全データセットの平均ではDeep ANNを上回らなかった。CNN-1DおよびCNN-LSTMも一定の性能を示したものの、複雑な構造による明確な改善は得られなかった。CWT + CNN-2Dの予備実験では平均R²が0.699となり、現設定ではCNN-1Dより低い結果であった。

最も重要な結果は、未知温度への汎化性能が著しく低いことである。Phase 8では多くの条件でR²が負となり、thermal driftが実運用上の主要な障害であることが明らかになった。

以上より、現在までにモデル比較の基準、同一温度内での有効なANN構造、各時系列モデルの特徴、および現行手法の限界を明確にできた。次の段階では、同一温度内の精度をわずかに向上させることよりも、未知温度に適応するためのcalibration、fine-tuning、temperature conditioning、およびdomain adaptationを重点的に検討する。
