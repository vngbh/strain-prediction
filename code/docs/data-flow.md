# データフロー — ひずみ予測モデル

## 生データの構造

```
data/dataset{1-4}.csv
  列: Idx | Experiment | Temperature | Electrode1_resistance | Electrode2_resistance | Strain
  ds1=33°C  ds2=43°C  ds3=52°C  ds4=62°C
  (各データセット約 3,000〜8,000 サンプル、複数実験を結合)
```

**全フェーズ共通の分割方法：** 先頭 70%（訓練）/ 末尾 30%（テスト） — `shuffle=False` で時系列順を保持。
スケーラーは必ず X_train のみに `fit` し、X_test には `transform` のみ適用（データリーク防止）。

---

## Phase 2 — ベースライン ANN（指導教員モデルの再現）

**目的：** 指導教員の元モデルをそのまま再現し、正しい基準値を確立する。

```
生データ      →  正規化           →  モデル入力    →  モデル構造       →  出力
(n, 2)           MinMaxScaler        (n, 2)           Dense(4, relu)      Strain
E1抵抗, E2抵抗   X_trainのみfit                       Dense(1)            スカラー/サンプル
```

- **入力特徴量：** 電極1抵抗（E1）、電極2抵抗（E2）の2次元
- **変換：** MinMaxScaler で [0, 1] に正規化するのみ
- **モデルが学ぶもの：** 瞬間的な抵抗値 → ひずみ の静的なマッピング

---

## Phase 3 — 特徴量エンジニアリング

**目的：** 同じ（小さな）アーキテクチャのまま特徴量だけ変えてどれが効くか確認する。

```
生データ      →  派生特徴量の追加           →  正規化    →  モデル入力    →  モデル構造       →  出力
(n, 2)           delta_R = E1 − E2            MinMax       (n, k)           Dense(4, relu)      Strain
                 R_ratio  = E1 / E2                        k ∈ {2,3,4,5}   Dense(1)
                 Temperature（温度）
```

- **派生特徴量の意味：**
  - `delta_R`：2電極の抵抗差 → ひずみの非対称な変形を捉える
  - `R_ratio`：抵抗比 → 絶対値ではなく相対変化に着目
- 4種類の特徴量セットをアーキテクチャ固定で比較 → 特徴量の貢献を単独評価

---

## Phase 4 — 深層 ANN（2×2 アブレーション実験）

**目的：** アーキテクチャと特徴量を同時に変えず、一方ずつ変化させて効果を分離する。

```
生データ      →  派生特徴量（セルによる）    →  正規化    →  モデル入力      →  モデル構造                →  出力
(n, 2)           delta_R, R_ratio, Temp         MinMax       (n, 2 or 5)       Cell A/B（小さい）：          Strain
                 （セル B, D のみ追加）                                            Dense(4, relu)
                                                                                  Dense(1)
                                                                               Cell C/D（中規模）：
                                                                                  Dense(64, relu)
                                                                                  Dense(32, relu)
                                                                                  Dense(16, relu)
                                                                                  Dense(1)
```

| セル | アーキテクチャ | 特徴量 | エポック |
| ---- | ------------ | ------ | ------- |
| A | 小（4ユニット） | E1+E2（2次元） | 50 |
| B | 小（4ユニット） | 全5特徴量 | 50 |
| C | 中（64-32-16） | E1+E2（2次元） | 300 + EarlyStopping |
| D | 中（64-32-16） | 全5特徴量 | 300 + EarlyStopping |

→ **セル C（中規模アーキテクチャ + E1+E2）が最良**。特徴量追加より容量増加の効果が大きかった。

---

## Phase 5 — LSTM

**目的：** 時系列の文脈を活用する。ANN残差に時間相関（0.13〜0.60）があることから、過去の信号が現在のひずみに影響していると仮定。

```
生データ      →  正規化    →  スライディングウィンドウ（WIN=20）     →  モデル入力       →  モデル構造              →  出力
(n, 2)           MinMax       (n−20, 20, 2)                             (n−20, 20, 2)      LSTM(64, return_seq=True)   Strain_t
E1, E2           X_train      各サンプル = 時刻 t の直前20ステップ                          LSTM(32)                    スカラー/ウィンドウ
                              [E1_{t-19},...,E1_t], [E2_{t-19},...,E2_t]                    Dense(16, relu)
                                                                                            Dense(1)
```

- **ウィンドウの意味：** 1サンプルが「時刻 t の20ステップ前〜現在」という**連続した時系列**になる
- ANN はサンプルを独立に見るが、LSTM はウィンドウ内の順序関係を記憶して予測する

---

## Phase 6 — CNN-1D

**目的：** 畳み込みで局所的な時間パターン（変化の形状）を抽出する。

```
生データ      →  正規化    →  スライディングウィンドウ（WIN=20）  →  モデル入力       →  モデル構造                →  出力
(n, 2)           MinMax       (n−20, 20, 2)                          (n−20, 20, 2)      Conv1D(64, kernel=3, same)    Strain_t
E1, E2                                                                                   Conv1D(32, kernel=3, same)
                                                                                         GlobalAveragePooling1D        ← 時間次元をまとめる
                                                                                         Dense(16, relu)
                                                                                         Dense(1)
```

- **Conv1D が学ぶもの：** 信号の局所的な「形」（立ち上がり・急変など）
- **GlobalAvgPool1D：** 20タイムステップ全体を平均して固定長ベクトルに変換 → Dense へ渡す

---

## Phase 7 — CNN+LSTM ハイブリッド

**目的：** CNN の「局所パターン抽出」と LSTM の「長期依存関係の記憶」を組み合わせる。

```
生データ      →  正規化    →  スライディングウィンドウ（WIN=20）  →  モデル入力       →  モデル構造                →  出力
(n, 2)           MinMax       (n−20, 20, 2)                          (n−20, 20, 2)      Conv1D(64, kernel=3, same)    Strain_t
E1, E2                                                                                   Conv1D(32, kernel=3, same)
                                                                                         ↓ shape: (batch, 20, 32)      ← GlobalAvgPool しない
                                                                                         LSTM(64)                      ← CNN特徴量の時系列を読む
                                                                                         Dense(16, relu)
                                                                                         Dense(1)
```

- **Phase 6 との違い：** GlobalAvgPool1D を使わず、CNN 後の shape `(batch, 20, 32)` をそのまま LSTM に渡す
  - Phase 6：CNN → 時間次元を潰す → Dense（時系列情報を失う）
  - Phase 7：CNN → 時間次元を保持 → LSTM が CNN特徴量の流れを学ぶ（情報を失わない）

---

## Phase 8 — 温度間汎化テスト

**目的：** 訓練時に見ていない温度のデータに対してモデルが汎化できるか検証する。

新しいアーキテクチャなし。ANN P4 Cell C と LSTM P5 をそのまま使用。

```
訓練データ    →  複数データセット結合           →  正規化（結合trainでfit）  →  モデル入力           →  テストデータ
ds{a}+ds{b}+ds{c}（3温度）                                                     (n, 2) ANN          ds{d}（未知の温度）
                                                                                (n, 20, 2) LSTM
```

**テスト1（Leave-One-Out）：** 4通りの組み合わせで1データセットずつ除外して評価
**テスト2（外挿）：** 33〜52°C で学習 → 62°C で予測（最も現実的な困難なシナリオ）

---

## Phase 9 — ハイパーパラメータ自動探索（Optuna）

**目的：** Phase 4 Cell C と同じ ANN ファミリーで、手動固定していたパラメータを自動最適化する。

```
生データ      →  正規化    →  モデル入力    →  モデル構造（Optuna が決定）                        →  出力
(n, 2)           MinMax       (n, 2)           層数：1〜4                                            Strain
E1, E2           X_train                       各層ユニット数：{16, 32, 64, 128}
                                               Dropout率：0.0〜0.4（任意）
                                               学習率：10⁻⁴〜10⁻²（対数スケール）
```

- **探索プロセス：** Optuna が 50 trials（seed=0）実行 → 最良パラメータを選択 → 3 seed で再訓練して mean±std を取得
- TPE サンプラーを使用（ランダムサーチより効率的）

---

## Phase 10 — CWT + CNN-2D

**目的：** 1D 信号を時間-周波数の 2D 画像（スカログラム）に変換し、CNN-2D で周波数パターンも学習させる。

```
生データ      →  正規化    →  スライディングウィンドウ  →  CWT（チャネルごと）               →  モデル入力            →  モデル構造             →  出力
(n, 2)           MinMax       (n−64, 64, 2)               pywt.cwt(signal,                     (n−64, 32, 64, 2)        Conv2D(32, 3×3)           Strain_t
E1, E2           X_train      WIN=64                       scales=1..32,                                                  MaxPooling2D(2×2)
                                                           wavelet='morl')                       [32スケール,             Conv2D(64, 3×3)
                                                           → |係数| の絶対値                      64タイムステップ,        GlobalAvgPool2D
                                                           shape: (32, 64)/チャネル               2チャネル]              Dense(32, relu)
                                                                                                                          Dense(1)
```

- **CWT スカログラム（2D 画像）の意味：**
  - 横軸：時間（64ステップ）
  - 縦軸：周波数スケール（32段階）
  - 値：その時刻・その周波数での信号強度
- **CNN-1D との差：** CNN-1D は時間軸のパターンのみ → CWT+CNN-2D は「どの周波数が、いつ」強くなるかを同時に学ぶ
- ウィンドウ幅を WIN=64 に拡大（CWT は短すぎると周波数解像度が下がるため）

---

## 入力変換まとめ

| フェーズ | 生データ shape | 主な変換 | モデル入力 shape |
| ------- | ------------ | ------- | -------------- |
| P2 ベースライン | (n, 2) | MinMaxScaler | (n, 2) |
| P3 特徴量設計 | (n, 2) | 派生特徴量追加 → MinMaxScaler | (n, 2〜5) |
| P4 深層ANN | (n, 2〜5) | MinMaxScaler | (n, 2〜5) |
| P5 LSTM | (n, 2) | MinMaxScaler → ウィンドウ(20) | (n, 20, 2) |
| P6 CNN-1D | (n, 2) | MinMaxScaler → ウィンドウ(20) | (n, 20, 2) |
| P7 CNN+LSTM | (n, 2) | MinMaxScaler → ウィンドウ(20) | (n, 20, 2) |
| P8 温度間汎化 | (n, 2) 複数DS結合 | concat → MinMaxScaler | (n, 2) or (n, 20, 2) |
| P9 Optuna | (n, 2) | MinMaxScaler | (n, 2) |
| P10 CWT+CNN | (n, 2) | MinMaxScaler → ウィンドウ(64) → CWT | (n, 32, 64, 2) |

**全フェーズの出力：** 各サンプルに対するスカラー値 `Strain_t`（回帰問題）
